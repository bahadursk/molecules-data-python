**From your first line of code to machine learning for molecules and materials.**

This is an interactive, open book for anyone who works with chemistry: school students meeting Python for the first time, undergraduates analysing lab data, and researchers building models of molecules and materials. Every page is a Jupyter notebook. Press the 🚀 rocket at the top of any chapter to run it in Google Colab or Binder, change the code, and see what happens.

## What makes this book different

- **Chemistry first.** Every Python idea is introduced through a chemical problem: molar masses, titrations, spectra, kinetics, crystal structures.
- **Molecules everywhere.** Hundreds of structures, reaction schemes and colour-highlighted functional groups drawn live with RDKit and py3Dmol.
- **Machine learning across all of chemistry.** Two full parts take ML from first principles into medicinal, organic, analytical, physical and quantum chemistry, catalysis, polymers, batteries, photovoltaics, MOFs and materials discovery.
- **Three levels in one book.** Each chapter is tagged:

## Roadmap

| Part | Theme | You will be able to… |
|---|---|---|
| I | Python fundamentals | write clean, correct Python for any chemistry calculation |
| II | NumPy, pandas, Matplotlib, Seaborn, Plotly, SciPy, SymPy | analyse, fit and plot real lab data |
| III | RDKit, py3Dmol, chemical databases | draw, search, compare and build molecules in code |
| IV | Kinetics, thermodynamics, spectroscopy, quantum, MD, crystals | solve physical-chemistry problems numerically |
| V | ML foundations | build, validate and explain ML models on chemical data |
| VI | ML across chemistry and materials science | apply ML in your own research field |
