# Appendix C: Glossary

Short definitions of terms used across the book, with the chapter where each is introduced. Chemistry terms are marked ⚗️, programming terms 🐍 and machine-learning terms 🤖.

```{glossary}
Active learning
  🤖 A strategy in which the model chooses which experiment or calculation to run next, usually where it is most uncertain or most promising. Chapters 35, 47.

Acquisition function
  🤖 The rule that turns a model's prediction and uncertainty into a score for choosing the next experiment, e.g. expected improvement (EI) or upper confidence bound (UCB). Chapter 35.

Aleatoric uncertainty
  🤖 Uncertainty due to genuine noise in the system or measurement; more data does not reduce it. Contrast {term}`Epistemic uncertainty`. Chapter 51.

Applicability domain
  🤖 The region of chemical or feature space in which a model's predictions can be trusted, usually defined by similarity to the training data. Chapters 36, 51.

Array
  🐍 A NumPy object holding a grid of numbers of one type, supporting fast vectorised arithmetic. Chapter 12.

Arrhenius equation
  ⚗️ $k = A e^{-E_a/RT}$, relating a rate constant to temperature through an activation energy. Chapters 1, 25, 50.

Bayesian optimisation
  🤖 Optimising an expensive function by fitting a probabilistic surrogate model (often a Gaussian process) and choosing each new point with an {term}`Acquisition function`. Chapter 35.

Calibration (of probabilities)
  🤖 The property that predicted probabilities match observed frequencies: of all predictions of 0.8, about 80 % should be correct. Chapter 51.

Calibration curve
  ⚗️ In analytical chemistry, a plot of instrument response against known concentration, used to determine unknowns. Chapters 12, 27.

Canonical SMILES
  ⚗️ A unique SMILES string for a molecule, generated by a fixed algorithm so that identical molecules give identical strings. Chapter 19.

Chemometrics
  ⚗️🤖 The application of statistics and multivariate analysis (PCA, PLS) to chemical data, especially spectra. Chapters 33, 39.

Class
  🐍 A template for creating objects that bundle data (attributes) with behaviour (methods). Chapter 10.

Cross-validation
  🤖 Estimating performance by repeatedly training on part of the data and testing on the rest. Chapter 31.

Data leakage
  🤖 Information about the test set, or about the label, reaching the model during training, which makes reported performance unrealistically good. Chapters 31, 51.

Descriptor
  ⚗️🤖 A number computed from a molecular structure, such as molecular weight, logP or TPSA. Chapters 20, 32.

DFT (density functional theory)
  ⚗️ A quantum-chemical method that computes electronic energies from the electron density. Chapter 28.

Dictionary
  🐍 A Python mapping from keys to values, e.g. `{"H": 1.008}`. Chapter 4.

Digital twin
  🤖 A model of a specific physical system that is continually updated with live data and used to answer what-if questions. Chapter 50.

Drift
  ⚗️🤖 Slow change in an instrument's or sensor's response over time, which degrades models trained on early data. Chapters 48, 50.

Dual use
  The potential for a tool built for beneficial purposes to be misused to cause harm. Chapter 51.

Ensemble
  🤖 A collection of models whose combined prediction is usually more accurate, and whose disagreement estimates uncertainty. Chapters 31, 51.

Epistemic uncertainty
  🤖 Uncertainty due to lack of knowledge, which more data in the relevant region would reduce. Chapter 51.

FAIR principles
  Data and software should be Findable, Accessible, Interoperable and Reusable. Chapter 51.

Featurisation
  🤖 Turning a molecule or material into a fixed-length vector of numbers a model can use. Chapter 32.

Fingerprint
  ⚗️🤖 A bit vector recording the presence of substructures in a molecule, e.g. Morgan (ECFP) or MACCS keys. Chapters 21, 32.

Function
  🐍 A named, reusable block of code that takes inputs (arguments) and returns an output. Chapter 6.

Gaussian process
  🤖 A probabilistic model that predicts a mean and an uncertainty for every input, defined by a kernel describing how similar two inputs are. Chapters 35, 50.

Generative model
  🤖 A model that proposes new molecules or materials rather than only predicting properties of given ones. Chapter 45.

Graph neural network (GNN)
  🤖 A neural network that operates directly on a molecular graph by passing messages between bonded atoms. Chapter 34.

Hückel theory
  ⚗️ A simple model of π molecular orbitals in conjugated molecules, built from a connectivity matrix. Chapters 12, 28.

Hybrid (grey-box) model
  🤖 A model combining known physical equations with machine-learned components for the unknown parts. Chapter 50.

Hyperparameter
  🤖 A setting chosen before training (tree depth, learning rate, number of PLS components), not learned from the data directly. Chapter 31.

InChI / InChIKey
  ⚗️ The IUPAC International Chemical Identifier and its fixed-length hashed form, used to identify molecules uniquely. Chapter 19.

Kernel
  🤖 A function measuring similarity between two inputs, used by Gaussian processes and kernel ridge regression. Chapters 35, 40.

Lipinski's rule of five
  ⚗️ A guideline that orally active drugs usually have MW ≤ 500, logP ≤ 5, ≤ 5 H-bond donors and ≤ 10 acceptors. Chapter 20.

List
  🐍 An ordered, mutable sequence in Python, e.g. `[1.008, 4.003]`. Chapter 4.

logP
  ⚗️ The base-10 logarithm of the octanol–water partition coefficient; a measure of lipophilicity. Chapter 20.

Machine-learned interatomic potential
  ⚗️🤖 A model trained on quantum-mechanical energies and forces that predicts them for new geometries at much lower cost. Chapter 40.

Model card
  🤖 A short structured document stating what a model is for, how it was trained and tested, and its limitations. Chapter 51.

Molecular dynamics
  ⚗️ Simulating atomic motion by integrating Newton's equations with a force field. Chapter 29.

Morgan fingerprint (ECFP)
  ⚗️🤖 A circular fingerprint built by iteratively hashing each atom's neighbourhood up to a given radius. Chapters 21, 32.

Out-of-distribution (OOD)
  🤖 An input unlike anything in the training data, for which predictions are unreliable. Chapter 51.

Overfitting
  🤖 Fitting noise in the training data, so that the model performs well on training data and poorly on new data. Chapter 31.

Pareto front
  🤖 The set of candidates for which no objective can be improved without worsening another. Chapter 47.

PCA (principal component analysis)
  🤖 Finding orthogonal directions of maximum variance, used for visualisation and compression. Chapters 33, 39.

pIC₅₀
  ⚗️ −log₁₀ of the half-maximal inhibitory concentration in mol L⁻¹; higher means more potent. Chapter 36.

PLS (partial least squares)
  🤖 A regression method that finds latent components explaining both the inputs and the target; the chemometrics workhorse. Chapters 39, 48, 50.

Random forest
  🤖 An ensemble of decision trees, each trained on a bootstrap sample with random feature subsets. Chapter 31.

Reaction SMARTS
  ⚗️ A SMARTS pattern describing a transformation, with mapped atoms, used to apply reactions in RDKit. Chapter 22.

Retrosynthesis
  ⚗️ Planning a synthesis backwards from the target molecule to available starting materials. Chapter 37.

Scaffold
  ⚗️ The core ring system and linkers of a molecule after removing side chains (Bemis–Murcko scaffold). Chapters 21, 36.

Scaffold split
  🤖 A train/test split that puts all molecules with the same scaffold on the same side, testing generalisation to new chemotypes. Chapter 36.

Shapley value
  🤖 A fair attribution of one prediction's deviation from the average to each input feature. Chapter 51.

SMARTS
  ⚗️ A pattern language for substructure searching, extending SMILES with wildcards and logic. Chapter 21.

SMILES
  ⚗️ Simplified Molecular-Input Line-Entry System: a line notation for molecules, e.g. `CCO` for ethanol. Chapter 19.

Soft sensor
  ⚗️🤖 A model that infers a hard-to-measure quantity (e.g. concentration) from easily measured ones (e.g. temperature, spectra). Chapter 50.

String
  🐍 A sequence of characters, e.g. `"NaCl"`. Chapter 3.

Tanimoto similarity
  ⚗️🤖 The ratio of shared to total "on" bits in two fingerprints; 1 means identical. Chapter 21.

TPSA
  ⚗️ Topological polar surface area: the summed surface contribution of polar atoms, predicting membrane permeability. Chapter 20.

Transformer
  🤖 A neural network architecture based on attention, used in language models and in SMILES-based chemistry models. Chapters 45, 46.

Tuple
  🐍 An ordered, immutable sequence, e.g. `("C", 12.011)`. Chapter 4.

U-Net
  🤖 A convolutional network with an encoder, a decoder and skip connections, widely used for image segmentation. Chapter 49.

Vectorisation
  🐍 Writing operations on whole arrays rather than element-by-element loops, for speed and clarity. Chapter 12.

Virtual screening
  ⚗️🤖 Computationally ranking a large library to choose a small number of candidates for experiment. Chapters 36, 47.
```
